    Security
    Password Protection
    PasswordNot set
    Sign out all devices

    Signs out every browser and device, including this one. Use it if you think a session may have been left open or compromised. Your password does not change.

    Leave blank to keep existing password. Min 8 characters. For stronger protection, consider placing the dashboard behind a dedicated authentication proxy. This built-in password is a lightweight gate, not a full authentication layer.
